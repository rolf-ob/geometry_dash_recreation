DOWNLOAD AND RUN:
Click the latest release and download the zip file. 
Extract the zip file and open the folder. 
Run the main/main.exe file, NOT the one named main.py. 
There may be a pop-up saying "Windows protected your PC", in that case press "More info" -> Run anyway unless you don't trust me I guess. 

Go to the Main Menu (Q, E) for controls or if you're unsure of anything. 

Don't use the operator controls (H, B) unless you're absolutely sure what you're doing.
